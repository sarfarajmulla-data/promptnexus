How it works

  1. 1
    Describe the situation

    Plain language. One line is enough. You do not need to know prompting.

  2. 2
    It works out what is missing

    Intent, task type, constraints, risks and the target model's limits.

  3. 3
    Take the prompt

    Structured, red-teamed, scored — with every line traceable to its source.

Capabilities

Built for one model

Length, formatting and structure adapt to the model you are using instead of a generic template.

Red-teamed before delivery

Failure modes are checked and repaired in place, then reported rather than hidden.

Honest by construction

Unknowns become labelled assumptions. Nothing about you is invented.

Works with no key

No-AI mode runs the full engine locally. Adding a provider key is optional and stays server-side.
